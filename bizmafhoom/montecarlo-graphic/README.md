# Monte Carlo — 15s B-roll (1080×1920, 30fps)

```bash
node build/simulate.mjs   # GBM: S0=100, μ=8%, σ=25%, 252 steps, 1,000 runs, seed 20260924 → assets/sim-data.js + sim.json
node build/sfx.mjs        # SFX stem cue-locked to assets/beats.js → assets/sfx.wav (-12 dBFS peak)
node build/sync-kit.mjs   # copy ../kit → vendor/kit
npx hyperframes lint && npx hyperframes check
npx hyperframes render -q delivery -o ../out/montecarlo-graphic.mp4
```

`assets/beats.js` is the single timing source for visuals and SFX.
`assets/sim.json` is the audit trail for every on-screen number.

`assets/sfx.wav` is generated by `build/sfx.mjs` and not committed; the delivered stem is `../out/montecarlo-graphic-sfx.wav`.
